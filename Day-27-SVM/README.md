# Day 27 – Support Vector Machine (SVM)

Welcome to **Day 27** of my AI/ML Engineer Bootcamp journey! Today, I explored **Support Vector Machine (SVM)**, a supervised Machine Learning algorithm used for classification and regression.

---

## 📌 Objective

Understand how SVM uses decision boundaries, margins, and kernel functions to classify data and predict continuous numerical values.

---

## 📚 Topics Covered

- ✅ Introduction to Support Vector Machine
- ✅ Support Vector Classification (SVC)
- ✅ Support Vector Regression (SVR)
- ✅ Hyperplane and Decision Boundary
- ✅ Support Vectors and Margin
- ✅ Linear and Nonlinear SVM
- ✅ Kernel Functions: Linear, Polynomial, RBF, and Sigmoid
- ✅ Hyperparameters: `C`, `gamma`, `degree`, and `epsilon`
- ✅ Feature Scaling with `StandardScaler`
- ✅ Pipelines using `make_pipeline`
- ✅ Classification Evaluation
- ✅ Regression Evaluation
- ✅ Practical Student Pass/Fail Classification
- ✅ Practical Car Price Regression

## 💡 Why SVM?

SVM can model linear and nonlinear patterns and is useful for classification and regression. Feature scaling and appropriate kernel and parameter selection are important for effective performance.
