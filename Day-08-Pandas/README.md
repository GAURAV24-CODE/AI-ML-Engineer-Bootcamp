Welcome to **Day 8 of the AI/ML Engineer Bootcamp**.

## 🎯 Day 8 Goal

Learn how to use Pandas to:

* Create Series and DataFrames
* Load datasets
* Inspect data
* Select rows and columns
* Filter data
* Sort data
* Add and modify columns
* Handle missing values
* Remove duplicates
* Perform basic data analysis

## 💡 AI/ML Connection

Pandas is heavily used before machine learning.

Typical workflow:

```text
Raw Dataset
     ↓
Pandas
     ↓
Data Cleaning
     ↓
Data Analysis
     ↓
Feature Engineering
     ↓
Visualization
     ↓
Machine Learning
```

Pandas helps prepare real-world datasets before training ML models.
