# Day 26 – Random Forest

Welcome to **Day 26** of my AI/ML Engineer Bootcamp journey! Today, I explored **Random Forest**, an ensemble Machine Learning algorithm that combines multiple Decision Trees to improve predictive performance.

## 📌 Objective

## 💡 Why Random Forest?

Random Forest often improves stability and generalization compared with a single Decision Tree by combining predictions from many trees. It is widely used for classification and regression tasks.
