# Day 29 – K-Means Clustering

Welcome to **Day 29** of my AI/ML Engineer Bootcamp journey! Today, I explored **K-Means Clustering**, an unsupervised Machine Learning algorithm that groups similar data points into clusters.

---

## 📌 Objective

Understand how K-Means groups data using centroids and distance measurements to identify patterns in unlabeled datasets.

---

## 📚 Topics Covered

- ✅ Introduction to Clustering
- ✅ Supervised vs. Unsupervised Learning
- ✅ K-Means Algorithm
- ✅ Centroids and Cluster Assignment
- ✅ Euclidean Distance
- ✅ Within-Cluster Sum of Squares (WCSS / Inertia)
- ✅ K-Means++ Initialization
- ✅ Elbow Method
- ✅ Silhouette Score
- ✅ Feature Scaling
- ✅ Model Training and Cluster Visualization
- ✅ Customer Segmentation Example

## 💡 Why K-Means?

K-Means is useful for discovering groups in unlabeled data. Common applications include customer segmentation, grouping similar products, and exploring patterns in datasets.
