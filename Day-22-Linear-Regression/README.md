# Day 22 – Linear Regression

Welcome to **Day 22** of my AI/ML Engineer Bootcamp journey! Today, I explored **Linear Regression**, a supervised Machine Learning algorithm used to predict continuous numerical values.

---

## 📌 Objective

Understand how Linear Regression models relationships between input features and a numerical target.

---

## 📚 Topics Covered

- ✅ Introduction to Linear Regression
- ✅ Simple Linear Regression
- ✅ Multiple Linear Regression
- ✅ Independent and Dependent Variables
- ✅ Regression Equation
- ✅ Model Training using `fit()`
- ✅ Predictions using `predict()`
- ✅ Model Evaluation
- ✅ Mean Absolute Error (MAE)
- ✅ Mean Squared Error (MSE)
- ✅ R² Score

## 💡 Why Linear Regression?

Linear Regression is a fundamental regression algorithm used to estimate continuous values such as house prices, sales, and demand. It provides a useful baseline for many predictive analytics problems.
