## 💡 Why Model Evaluation?

Model evaluation helps determine whether a machine learning model performs well on unseen data. It helps identify weaknesses, compare algorithms, detect overfitting, and select a model that suits the real-world problem.

---

## 🚀 Key Takeaways

- **Classification:** Accuracy, Precision, Recall, F1-score, ROC-AUC
- **Regression:** MAE, MSE, RMSE, R²
- **Validation:** Train-Test Split and Cross-Validation
- **Model Improvement:** Feature Engineering, Hyperparameter Tuning, and Overfitting Control
